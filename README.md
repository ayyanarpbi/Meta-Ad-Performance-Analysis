# 📊 Meta Ad Performance Analysis – BI Reporting Dashboard

## 🔹 Project Overview
This project focuses on building a BI reporting dashboard in Microsoft Power BI to track and monitor paid advertising performance on Facebook and Instagram.

The dashboard helps business and marketing teams understand campaign performance, compare platforms, and take data-driven decisions.

---

## 🎯 Business Objective
The objective of this report is to:
- Monitor overall ad performance
- Compare Facebook vs Instagram effectiveness
- Track engagement and conversions
- Support budget optimization decisions
- Provide a single source of truth for ad performance reporting

---

## 🛠 Tools Used
- Microsoft Power BI Desktop
- Power BI Service
- CSV files (Data Source)
- Power Query (Data Cleaning & Preparation)
- MySQL (Data Validation)

---

## 📂 Data Preparation
- Imported multiple CSV files into Power BI
- Cleaned and standardized data using Power Query
- Removed null and invalid records
- Validated key metrics using MySQL

---

## 📌 Report Scope
### Included
- Paid ad campaigns on Facebook and Instagram

### Excluded
- Organic engagement
- Other Meta platforms (Messenger, Audience Network)

---

## 📊 Key Metrics Reported
- Impressions
- Clicks
- Engagements
- Purchases
- CTR
- Conversion Rate
- Total Budget
- Average Budget per Campaign

---

## 📈 Dashboard Highlights
- Platform performance comparison (Facebook vs Instagram)
- Audience analysis by gender and age group
- Country-level performance overview
- Monthly, weekly, and hourly engagement trends
- Ad type performance comparison

---

## 📊 Business Insights
- Identified best-performing platforms and ad types
- Highlighted high-engagement audience segments
- Discovered peak engagement periods
- Supported budget allocation and optimization decisions

---

## 🚀 How to Use
- Open the Power BI (.pbix) file
- Refresh the data source
- Use slicers to analyze performance interactively
